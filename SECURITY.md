# Security policy

Author: Paul Bryant

These are Prism and AHV automation examples. No workflow has been validated against a live environment for this repository. API behavior depends on the installed product release. See [script status](docs/script_status.md).

If you find a security problem, use GitHub's private vulnerability reporting for this repository when available. If that option is unavailable, open a public issue that asks for a private contact method without including exploit details, credentials, or customer data. The maintainer will coordinate a private report.

Do not put live credentials in example environment files, source, tests, logs, or issue reports. Revoke and replace any credential that was committed or disclosed.
